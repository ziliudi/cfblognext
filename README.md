# CFBlog-Plus

CFBlog-Plus 是基于原始开源项目 `gdtool/cloudflare-workers-blog` 二次开发的轻量博客程序，运行于 Cloudflare Workers，使用 Cloudflare KV 保存文章和站点数据。

本仓库持续维护当前可用代码与功能。原作者曾提供的演示站、部署教程、更新日志、源码解读页面及讨论群等外部入口已不再列出；相关域名目前无法稳定访问，请以本仓库中的代码和文档为准。

## 项目特点

- 使用 Cloudflare Workers 和 KV，无需额外数据库。
- 使用 Cloudflare 缓存 HTML，减少 KV 读写并提升访问速度。
- 后台支持文章管理及 Markdown 内容。
- 支持文章置顶、隐藏、静态搜索等功能。
- 后台编辑器已增强为富文本编辑体验，并保留 Markdown 内容兼容。
- 支持草稿箱和定时发布。
- 保持轻量部署方式，不依赖必须付费的第三方服务。

## 后台内容工作流：草稿箱与定时发布

- 编辑/新建文章时，可选择“立即发布”“保存为草稿”或“定时发布”。
- 草稿可以先保存未完成内容，仅在后台文章列表和“草稿箱”中显示；不会出现在首页、分类、标签、搜索索引和站点地图中，直接访问草稿 URL 也会返回 404。
- 定时文章必须设置未来时间；到达时间前不会公开，直接访问 URL 也会返回 404。到期后由 Worker 自动转为已发布并刷新标签索引。
- 后台首页新增“草稿箱”和“定时发布”列表，可点击标题继续编辑。文章索引更新时会自动递增前台缓存版本，不依赖 Cloudflare Zone API Token 也能避免继续命中旧缓存；如配置了缓存清理凭据，还会额外执行全站清理。

### 启用自动定时发布

在 Cloudflare Dashboard 中打开该 Worker：

1. 进入 **Triggers（触发器）**。
2. 在 **Cron Triggers** 添加表达式 `* * * * *`（每分钟检查一次）。
3. 保存后按 Dashboard 提示重新部署 Worker。

定时发布依赖 Cron Trigger；如果没有配置，定时文章会继续保持未公开状态，直到配置触发器并执行到期任务。发布时间按编辑器浏览器的本地时区选择，保存后转换为 UTC 时间。
