# CFBlog-Plus

CFBlog-Plus 是基于原始开源项目 `gdtool/cloudflare-workers-blog` 二次开发的轻量博客程序，运行于 Cloudflare Workers，使用 Cloudflare KV 保存文章和站点数据。

本仓库持续维护当前可用代码与功能。原作者曾提供的演示站、部署教程、更新日志、源码解读页面及讨论群等外部入口已不再列出；相关域名目前无法稳定访问，请以本仓库中的代码和文档为准。

## 项目特点

- 使用 Cloudflare Workers 和 KV，无需额外数据库。
- 使用 Cloudflare 缓存 HTML，减少 KV 读写并提升访问速度。
- 后台支持文章管理及 Markdown 内容。
- 支持文章置顶、隐藏、静态搜索等功能。
- 后台编辑器已增强为富文本编辑体验，并保留 Markdown 内容兼容。
- 支持草稿箱和定时发布。
- 保持轻量部署方式，不依赖必须付费的第三方服务。

## 后台内容工作流：草稿箱与定时发布

- 编辑/新建文章时，可选择“立即发布”“保存为草稿”或“定时发布”。
- 草稿可以先保存未完成内容，仅在后台文章列表和“草稿箱”中显示；不会出现在首页、分类、标签、搜索索引和站点地图中，直接访问草稿 URL 也会返回 404。
- 定时文章必须设置未来时间；到达时间前不会公开，直接访问 URL 也会返回 404。到期后由 Worker 自动转为已发布并刷新标签索引。
- 后台首页新增“草稿箱”和“定时发布”列表，可点击标题继续编辑。文章索引更新时会自动递增前台缓存版本，不依赖 Cloudflare Zone API Token 也能避免继续命中旧缓存；如配置了缓存清理凭据，还会额外执行全站清理。

### 启用自动定时发布

在 Cloudflare Dashboard 中打开该 Worker：

1. 进入 **Triggers（触发器）**。
2. 在 **Cron Triggers** 添加表达式 `* * * * *`（每分钟检查一次）。
3. 保存后按 Dashboard 提示重新部署 Worker。

定时发布依赖 Cron Trigger；如果没有配置，定时文章会继续保持未公开状态，直到配置触发器并执行到期任务。发布时间按编辑器浏览器的本地时区选择，保存后转换为 UTC 时间。

## 部署说明

请以当前仓库中的 Worker 源码、Cloudflare Dashboard 配置和本文档为准。原项目作者提供的旧演示站、旧教程及旧更新日志链接已移除，避免访问失效域名。

### 首次部署前必须修改的配置

打开 `index_plus.js` 顶部的 `ACCOUNT` 配置区：

- 将 `user` 改为自己的后台用户名。
- 将 `password` 改为足够长的随机密码（建议至少 20 位）。
- `third_token` 是可选的只读导出令牌；不需要外部导出时保持空字符串。

**安全提示：** 仓库中的用户名和密码是强制修改占位值。若仍保留 `CHANGE_ME_` 占位内容，后台认证会拒绝登录，这是预期的安全行为。不要把真实密码或 Token 提交到公开仓库。

同时确认 `OPT` 中的站点域名、主题地址，以及 Cloudflare Worker 的 KV 绑定名称与代码配置一致。升级已有博客前请先备份 KV 数据，不要删除或重新创建原有 Namespace。

### 安全加固说明

- 后台认证拒绝空凭据及仓库占位凭据。
- 后台写操作仅允许 POST，读取操作使用 GET/HEAD 白名单，避免通过 GET 链接触发删除、发布或保存。
- 后台写请求会校验 Origin / Fetch Metadata；请求体声明长度超过限制时拒绝处理。
- Sitemap 的日期、更新频率和优先级字段使用白名单校验，避免异常 KV 数据破坏 XML。
- 响应统一添加 `X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy` 和 `Permissions-Policy` 等安全响应头。
- 文章编辑接口会校验文章 ID、字段长度、分类/标签数量，并要求定时发布时间有效且在未来。

这些措施属于基础防护，不等同于完整渗透测试；部署后仍应验证主题兼容性和后台各项操作。
